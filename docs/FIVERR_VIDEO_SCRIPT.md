# Fiverr Hero Gig Video – Script & Storyboard V1

**Target length:** 45–55 seconds  
**Format:** 16:9, 1080p recommended  
**Tone:** calm, senior, concise, business-focused  
**Primary CTA:** Send your Power BI file for a professional review.

## Final spoken script

Hi, I’m Daniel. I help businesses improve Power BI reports by looking beyond whether a dashboard simply works.

I review your data model, relationships, DAX, Power Query, performance and dashboard usability using a structured Power BI Health Assessment.

You receive a clear 0-to-100 Health Score, prioritized findings, quick wins and actionable next steps.

In this verified demo case, the report improved from 78 to 98 points after the recommended changes were applied.

My goal is simple: help you understand what to fix before you spend time fixing it.

Send me your Power BI file and I’ll give you a professional, business-focused review.

## Shot plan

| Time | Visual | Voice / on-screen message |
|---|---|---|
| 0–6s | Daniel on camera, neutral background | “Hi, I’m Daniel…” |
| 6–14s | Screen capture: report cover and Power BI model | “I review your data model…” |
| 14–24s | Fast cuts: Relationships, DAX, Performance, UX | Show four assessment areas |
| 24–34s | Health Score + priority matrix | “0-to-100 Health Score…” |
| 34–43s | Verified 78 → 98 demo result | “In this verified demo case…” |
| 43–50s | Daniel on camera | “My goal is simple…” |
| 50–55s | CTA graphic | “Send me your Power BI file…” |

## On-screen text
- POWER BI EXPERT REVIEW
- Data Model · DAX · Performance · UX
- 0–100 Health Score
- Prioritized Findings
- Verified Demo: 78 → 98
- Know what to fix before you spend time fixing it.

## Recording guidance
- Speak slightly slower than normal conversation.
- Maintain eye contact with the camera.
- Prioritize clean audio.
- Use a neutral/uncluttered background.
- Avoid exaggerated sales language.
- Use demo report/model captures only; no customer data.
